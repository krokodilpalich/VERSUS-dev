## ADR: локальное S3

Официальные MinIO Docker Hub/Quay образы недоступны (denied/unauthorized); сборка исходников блокируется доступом к storage.googleapis.com. Используется стабильный SeaweedFS 3.97, закреплённый digest, с S3 API и обязательной аутентификацией. API приложения не зависит от провайдера; можно переключить S3_ENDPOINT на MinIO. Это инфраструктурное отклонение, не mock файлов. Непроверенные попытки MinIO не используются.
